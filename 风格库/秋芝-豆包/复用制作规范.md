# 秋芝-豆包：复用制作规范

下面是基于原片观察提出的实施建议。色值、尺寸、时长均是可调整的制作起点，不是原项目文件中读取的参数。

## 一、画面系统

| 组件 | 建议实现 | 原片依据 |
| --- | --- | --- |
| 主舞台 | 1920×1080，黑/近黑底 `#080808`；软件窗口以可读性决定大小 | 00:24、01:27 等 |
| 真人段 | 中近景，柔和面部主光，背景紫光；身体手势保留完整 | 00:15、03:36、07:45 |
| 软件窗口 | 建议宽占画面 82%–90%，顶端与四周留安全区，圆角 16–28 px | 大多数白色软件界面 |
| 圆形头像 | 左下角，建议直径 150–190 px；位置避开按钮、材料名和字幕 | 00:24 起反复出现 |
| 字幕 | 白色粗黑体配深色底/边，底部居中；1080p 建议 34–42 px，按语义断句 | 原片字幕为短句白字配深底 |
| 章节导航 | 蓝 `#2388FF`、黄 `#F5DF27`、绿 `#39C872`、红 `#E94254`；四行布局和编号固定 | 00:45、07:39 |
| 关键词标签 | 黄 `#F5ED16` 或荧光绿 `#B9FF00` 底，黑色粗字；仅强调少量词 | “汽车销售”“办公模式”等 |
| 提示词高亮 | 半透明黄条跟随当前句，避免盖住字形 | 01:27、03:00 |
| 局部强调 | 非当前区域压暗，当前块配橙色 `#FFAA42` 虚线框 | 06:15–06:45 |

字体可用授权明确的思源黑体/系统黑体完成相近层级。原片准确字体没有识别，不应在风格说明里写成确定字体名。不要把所有颜色同时用在同一张信息卡。

## 二、动效规则

1. **先确定观众要看什么，再动镜头。** 讲入口时定位按钮，讲指令时放大输入区，讲成果时切输出。
2. **一段口播只安排一个主要视觉动作。** 列表逐条揭晓、局部框选、软件窗口推近，避免竞争。
3. **推荐过渡尺度：**普通淡入/位移约 0.18–0.35 秒，读屏推近约 0.3–0.6 秒；这是复刻建议，非实测原片动画时长。
4. **信息应有停留时间。** 一行指令强调通常至少约 2–4 秒；复杂输出先给全貌，再给细节。以读懂内容为准。
5. **章节切换恢复导航。** 当前项亮起，已讲项保留，未来项弱化；让观众知道进度。
6. **真人大画面用在关系与评价。** 收益承诺、提出问题、结果评价、互动和结尾适合真人；操作连续区间尽量保留演示舞台。
7. **插入反应图要短而有因果。** 原片约 02:15 有反应插图，用于回应收费话题；不要每句都插梗。

## 三、脚本模板

> 你现在可能只用到了【工具的一小部分能力】。今天用【几个真实任务】看它能做什么。
> 假设我是【职业/角色】，手上有【资料】，现在需要【交付物】。以前要【手工步骤】。
> 现在先【选择材料/进入模式】，再告诉它【任务 + 约束 + 输出格式】。
> 这里注意【一项关键设置或接管环节】。
> 来看结果：【整体输出】。放大看这里：【证明完成的细节】。
> 所以这一项解决的是【一句话能力总结】。下一项是【能力导航】。
> 最后先选【一两个可立即实践的任务】，把它用起来。

推荐把每个案例拆成七个镜头职责：

| 镜头 | 必须交代的内容 | 可选画面 |
| --- | --- | --- |
| 场景 | 谁遇到了什么事 | 真人、职业卡通 |
| 材料 | 原始输入有哪些 | 文件夹、截图拼板 |
| 麻烦 | 传统步骤为什么费事 | 手机聊天、步骤对比 |
| 指令 | 想让工具做什么 | 输入框 + 分句高亮 |
| 执行 | 关键入口和控制点 | 真实录屏 + 圆形头像 |
| 验收 | 输出是否满足任务 | 成果全貌 + 细节放大 |
| 回收 | 学会了哪项能力 | 真人评价 + 章节导航 |

## 四、声音制作

本次只测量了原片混音响度，没有完成分轨音乐分析。不要把以下建议理解为原片音乐参数：

- 口播优先，背景音乐不妨碍中文辅音与操作说明。
- 章节揭晓、结果出现可以设置短提示音；长提示词读屏时减少干扰。
- 如要按平台制作母带，可另设约 -14 LUFS、真峰值不高于 -1 dBTP 的工作目标，并以目标平台要求和试听为准；不复制原片解码测得的 +1.70 dBTP 峰值。
- 对原片旁白语气的判断主要来自转写、字幕和表情：面向“你/我们”的教学口吻，反复用“举个例子”“看看结果”连接。具体语调、BGM 曲目和音效落点需要后续听辨。

## 五、复用前检查

- 章节卡上的能力是否都在后文兑现？
- 每个案例能否看到输入、关键过程和成果？
- 录屏是否真实对应旁白，是否保留必要接管步骤？
- 高亮是否与当前句一致，是否留足阅读时间？
- 头像和字幕是否遮住按钮、结果数值、文件名？
- 结果演示中的广告/动画是否被误当作主片包装风格？
- 字体、色值和动效建议是否与实际观察明确区分？
- 宣称“省了多少时间”“超过多少人”是否有依据？

本片最应继承的是解释路径与证据节奏；紫光、荧光色、卡通图是可替换的视觉选择。
