# 数据与证据说明

## 来源及审阅范围

- 本地输入：用户提供的 `03 秋芝-豆包.mp4`，37,749,141 字节。
- ffprobe：1920×1080，30 fps，视频轨 490.50 秒，容器 490.52 秒。
- 每秒抽取一帧，共 491 张，排为 21 张联系表；每 3 秒全片概览共 164 个采样点、9 张联系表。
- 人工查看了全片 3 秒概览，结合字幕与转写建立章节和关键画面分析；重点截图 25 张。
- 没有把采样审阅表述为全片逐帧观看，也没有完成声音事件级人工标注。

## 转写

使用本地 OpenAI Whisper base，中文提示、词级时间戳。TXT 和 JSON 保留未经校对的机器输出，繁体、谐音和英文误识别均可能存在。

例如 PDF 常识别成 PTF，Word、Skill、浏览器、秋芝等也有明显错误。机器输出用于检索与大致时间定位，不能直接当可发布字幕；联系表上的文本也沿用机器输出。正文用可见字幕校正了关键术语。

“258 字/分钟”只统计 ASR 文本的汉字数量并除以全片分钟数，没有排除停顿，没有完整计入英文，也没有校正漏识别。不是精确语速。

## 主播画面抽样

`主播全屏_3秒抽样.csv` 逐行列出 0、3、6……489 秒的判断。1 表示真人是主画面，包括旁边叠加手机或文字；左下角圆形画中画不算。25/164 = 15.24%。

这个比例只描述离散采样点。不能直接宣称“真人精确占 74.77 秒”，也没有统计真人连续镜头中位时长。

## 场景变化检测

命令核心：

```text
ffmpeg -i INPUT.mp4 -vf "scale=320:-1,select='gt(scene,0.25)',showinfo" -an -f null NUL
```

得到 64 个候选时间点。光效或大幅缩放可能误触发，局部高亮、细微推近、字幕、鼠标和滚动可能漏检。`候选切点.txt` 不等同于人工校验的 EDL。

间隔中位数与最大值在 0 秒、候选点、490.52 秒组成的边界序列上计算。最长间隔不是最长静止画面。

## 声音

使用原片音轨，而非转写用 MP3：

```text
ffmpeg -i INPUT.mp4 -vn -af "loudnorm=print_format=json" -f null NUL
```

取 `input_i`、`input_tp`、`input_lra`，分别为 -13.53 LUFS、+1.70 dBTP、3.90 LU。日志中的 output 值属于滤镜模拟处理，不是本报告的原片数据。未改动用户原视频。

没有做人声/音乐分离；无法从这项测量推断 BGM 自身音量、压低幅度、曲名、BPM 或重击次数。

## 可复现性

目录保存 `extract.py`、`transcribe.py`、`package.py`，反映本次处理逻辑。它们包含本机输入、模型与输出路径，换机器时须修改路径，并准备 FFmpeg、Pillow、OpenCV 和 Whisper 环境；不是跨机器即开即用的软件包。

原始视频不在此次提交中。原片尺寸与截图尺寸不同：重点图为 960×540，便于 GitHub 阅读，不适合作为无损制作素材。
